# 1978 Datsun 280Z Factory Service Manual & EFI Digital Knowledgebase

A digital, fully searchable, high-resolution documentation archive and knowledgebase for the **1978 Datsun 280Z**.

This project extracts, transcribes, and cross-references the complete Nissan Factory Service Manual (FSM), the factory EFI troubleshooting book, high-resolution color wiring diagrams, and AFM calibration guides into clean GitHub-flavored Markdown with segmented diagrams, torque charts, and symptom matrices.
